Esta página está hecha con tecnologías simples: HTML para la estructura, CSS para el diseño y JavaScript para que todo funcione. No usa framework ni build: se publica tal cual en Firebase Hosting, dentro del proyecto linea-tiempo-16fa4.
Los usuarios, inicios de sesión y datos de las líneas de tiempo se manejan con Firebase: Auth permite entrar con Google, correo o teléfono, y Firestore guarda los textos, fechas, eventos y configuraciones. Las imágenes se suben a Cloudinary y Firestore guarda solo sus links, para que la base de datos no se llene con archivos pesados.
Para publicar cambios: firebase deploy --only hosting,firestore.
Fuente usada en la página: Nunito Sans, cargada desde Google Fonts.
